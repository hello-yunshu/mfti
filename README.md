# MFTI — Mildly Fun Type Indicator

一份认真不到哪里去的人格小测。39 道题，四个核心轴，十个画像维度，匹配 16 种虚构角色。

👉 **在线体验：<https://mfti.hey.run/>**

> 纯属娱乐，不构成心理、医学或任何专业诊断。测试不会根据性别、性向、身体状态或关系状态推断你是谁。

## 它是什么

MFTI 是一个纯前端、无后端、无账号的趣味人格测试。题目围绕四个与身份无关的核心倾向展开：

- **审美偏好**：浪漫想象 ↔ 日常务实
- **社交能量**：社交充电 ↔ 独处充电
- **思考方式**：分析求证 ↔ 直觉随感
- **行动节奏**：计划推进 ↔ 即兴发挥

四个轴两两组合得到 16 种虚构角色。每道题的三个选项都使用同一套与语言无关的计分结构，切换中英文不会改变结果。

## 计分与结果

| 核心轴 | 代码 | 高位字母 | 低位字母 |
|--------|------|----------|----------|
| 审美偏好 / 想象浓度 | IM | P（想象派） | R（务实派） |
| 社交能量 / 社交电量 | SO | S（社交充电） | H（独处充电） |
| 思考方式 / 分析倾向 | AN | A（分析求证） | W（直觉随感） |
| 行动节奏 / 计划节奏 | PL | E（计划派） | I（即兴派） |

- 分类只使用上述四个核心轴，其余六个维度（审美投入、好奇探索、表达欲、仪式感、幽默值、情绪浓度）只用于结果页的十维画像，不参与分型。
- 每个维度的归一化范围根据**实际作答的题目**自动计算，不依赖硬编码常数；跳过题目不会被当作负面答案。
- 四个核心轴都接近中间时，结果会明确提示「你的答案比较均衡」，并给出最接近的轻松角色，而不是伪装成极鲜明的固定画像。
- 「你可能也会喜欢的角色」只做距离排序，不显示百分比，避免伪精确。
- 第 39 题不参与任何计分，单独改这一题不会改变分型。

## 隐私与本地存储

- 答案和结果默认只存在于当前页面内存中，**不会自动保存，也不会自动上传**。
- 只有用户主动点击「保存到本机」时，才会把最小结果（版本号、角色代码、十维分数、保存时间、语言）写入 `localStorage`。
- 不会保存答案原文，不使用 Cookie、统计脚本或第三方请求。
- 随时可以在首页或结果页点击「删除本机结果」。
- 旧版（schema < 2）的本地结果不会被当作新版结果展示，会提示删除后重新测试。

## 无障碍与动效

- 选项使用 `radiogroup` / `radio` 语义，方向键移动焦点，空格或回车选择，焦点可见。
- 免责声明弹窗支持 Escape 关闭、Tab 焦点循环，并在关闭后恢复焦点。
- 尊重 `prefers-reduced-motion`：减少动效时会关闭樱花粒子与装饰动画。
- 页面允许缩放，不锁定 `maximum-scale`。

## 本地运行

直接双击 `index.html` 即可，无需服务器。

需要重新生成压缩产物时：

```bash
npm ci
npm test          # 数据、引擎、静态结构测试
npm run build     # 压缩 JS/CSS，并用内容哈希更新 index.html 的引用版本
```

`npm run build` 是确定性的：同样的源码会生成同样的压缩文件和同样的 `?v=` 哈希，因此 CI 可以直接校验生成物是否与源码一致。

## CI

GitHub Actions 只做只读校验，不会自动提交：

1. `npm ci`
2. `npm test`
3. `npm run build`
4. `git diff --exit-code` —— 如果压缩产物或版本引用与源码不一致，CI 失败，交由人修复。

所有第三方 Action 均锁定到完整 commit SHA。

## 已知局限

- 这是一个娱乐性质的小测，**没有经过心理测量学验证**，不能用于招聘、教育、医疗或任何高风险决策。
- 角色描述是虚构创作，不代表对任何真实群体或个人的判断。
- 结果依赖用户当下的自我感受，重复测试出现变化是正常的。
